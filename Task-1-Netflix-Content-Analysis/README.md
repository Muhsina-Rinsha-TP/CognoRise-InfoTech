# Task 1: Netflix Content Analysis

## Project Overview
This project focuses on analysing the Netflix content dataset to identify patterns, trends and insights related to movies and TV shows. The analysis was performed using Python and various data analysis and visualisation libraries.

## Objectives
- Analyse the distribution of Movies and TV Shows.
- Identify the top countries contributing to Netflix content.
- Explore popular genres and their trends.
- Analyse movie durations and TV Show seasons.
- Perform statistical analysis to identify relationships in the dataset.

## Dataset
- **Dataset:** Netflix Titles Dataset
- **File:** `netflix_titles.csv`
- **Total Records:** 8,807
- **Features:** Title, Type, Director, Cast, Country, Date Added, Release Year, Rating, Duration and Listed In.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Project Workflow

1. Data Loading and Inspection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualisation
5. Statistical Analysis
6. Dashboard Creation
7. Key Findings and Interpretation

## Key Findings

- Movies represent approximately 69.6% of the Netflix catalogue, while TV Shows account for 30.4%.
- The United States contributes the highest number of titles, followed by India and the United Kingdom.
- International Movies is the most frequently listed genre, followed by Dramas and Comedies.
- The average movie duration is approximately 99.6 minutes.
- TV Shows have an average of 1.8 seasons.

## Statistical Analysis

The project includes:
- Chi-square test to examine the association between content type and audience category.
- Spearman correlation to analyse the relationship between release year and movie duration.
- Mann-Whitney U test to compare the duration of newer and older movies.
